# Glossary Template (도메인 공통어)

간단 설명: 핵심 용어를 명확히 정의하여 팀 전체의 공통 이해를 보장합니다.

---

## 사용자 (User)

**정의**: 서비스에 액세스하는 주체. 인증된 개인 또는 시스템.

**동의어**: 고객, account-holder

**사용 예시**: 사용자 이메일로 로그인

**관련 유스케이스**: UC-001 회원가입, UC-002 로그인

**API 매핑**: `components/schemas/User`

**소유자**: Product Owner

---

## 작성/변경 지침
- 각 용어는 `## 용어명 (English Name)` 형식으로 작성하세요.
- 소유자(Owner)를 명시하세요.
- 변경 시 변경 이유와 관련 유스케이스를 함께 기록하세요.
- 용어는 API 스펙, 문서, 테스트 케이스에 동일하게 사용하세요.
- 동의어가 없으면 "-" 또는 "없음"으로 표기하세요.
